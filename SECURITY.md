# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately.

**Do not open a public issue.** Instead, use one of the following methods:

- **GitHub Private Vulnerability Reporting**:  
  https://github.com/JensGrote/opencode-semantic-anchors/security/advisories/new

- **Direct contact**:  
  https://github.com/JensGrote

We will acknowledge receipt within 48 hours and provide an estimated timeline for a fix.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | ✅ Active development |

## Scope

This security policy covers:

- The `opencode-semantic-anchors` plugin code
- Configuration parsing and validation
- Plugin hook execution

Out of scope:

- Third-party dependencies (reported via their respective projects)
- The opencode platform itself
- User-defined contract configurations
