### API-Migration: AgentPlugin → funktionsbasierte Plugin-API
- opencode Plugin SDK hat sich geändert: von `AgentPlugin` Interface zu funktionsbasierter `Plugin` API
- Betroffene Dateien:
  - `02-architecture-constraints.md` — Constraint aktualisiert
  - `04-solution-strategy.md` — Source Anchor Referenz aktualisiert
  - `05-building-block-view.md` — Entry Point, Hook Handler, Custom Tools, Sequence-Diagramm
  - `06-runtime-view.md` — 4 Sequence-Diagramme (Blocked, Warn, Chat, Error)
  - `opencode-semantic-anchors-design.adoc` — Entry Point + Referenzen
- Neue API:
  ```typescript
  import type { Plugin, tool } from '@opencode-ai/plugin'
  export const MyPlugin: Plugin = async (ctx) => { return { hooks, tool } }
  ```
  - BLOCK: `throw new Error(...)`
  - WARN: `client.app.log(...)`
  - Custom Tools: `tool({ description, args, execute })`
- `chat.message` und `agent.activate` nicht mehr als dedizierte Hooks verfügbar
  - Ersatz via Event-System (`message.updated`, `session.created`)
